# Сервис подбора здорового питания

Веб-сервис для расчета КБЖУ и стоимости дневного рациона с учетом параметров пользователя, цели питания и ограниченного бюджета. Проект помогает сформировать рацион, проанализировать его соответствие нормам и получить рекомендации по корректировке.

## Технологии
- Python 3.x
- Django
- Pandas
- Plotly
- SQLite

## Основные возможности
- заполнение профиля пользователя;
- расчет нормы калорий и БЖУ;
- просмотр и фильтрация продуктов;
- создание рационов по датам;
- добавление и удаление продуктов из рациона;
- анализ рациона;
- рекомендации по продуктам;
- бюджетные рекомендации;
- дашборд с таблицей и графиками.
