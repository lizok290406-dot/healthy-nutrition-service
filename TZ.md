# Техническое задание на проект: Сервис подбора здорового питания для студентов с ограниченным бюджетом

## 1. Цель проекта
Разработка веб-сервиса, который помогает пользователю формировать дневной рацион с учетом личных параметров, цели питания, бюджета и норм КБЖУ. Сервис должен позволять рассчитывать калорийность, стоимость рациона, анализировать отклонения от целевых показателей и предлагать подходящие продукты.

## 2. Роли пользователей
- **Гость / пользователь**: может просматривать продукты, заполнять профиль, создавать рацион, добавлять продукты, анализировать рацион.
- **Администратор**: управляет категориями, продуктами, профилями, рационами и элементами рационов через Django admin.

## 3. Модели данных

### Profile
Хранит персональные параметры пользователя.
**Поля:** user, gender, age, weight, height, activity_level, goal, daily_budget.

### Category
Категория продукта.
**Поля:** name.

### Product
Информация о продукте и его пищевой ценности.
**Поля:** name, category, calories_per_100g, proteins_per_100g, fats_per_100g, carbs_per_100g, price_per_100g.

### Ration
Рацион пользователя на определенную дату.
**Поля:** user, date.

### RationItem
Элемент рациона.
**Поля:** ration, product, grams.

## 4. Ключевой функционал
- Пользователь заполняет профиль и получает расчет нормы калорий и БЖУ.
- Пользователь просматривает список продуктов с поиском, фильтрацией и сортировкой.
- Пользователь создает рацион на выбранную дату.
- Пользователь добавляет продукты в рацион и удаляет их.
- Сервис рассчитывает калории, белки, жиры, углеводы и стоимость рациона.
- Сервис сравнивает факт с нормой и показывает отклонения.
- Сервис формирует рекомендации по коррекции рациона.
- Сервис показывает дашборд с таблицей рационов и графиками по датам.

## 5. Внешние интеграции / Аналитика
Проект использует:
- **Pandas** для подготовки и обработки данных рационов;
- **Plotly** для визуализации динамики калорийности и стоимости рационов по датам.

## 6. Основные пользовательские сценарии
1. Пользователь открывает главную страницу и переходит к заполнению профиля.
2. Пользователь вводит свои параметры и сохраняет профиль.
3. Пользователь создает рацион на выбранную дату.
4. Пользователь добавляет продукты в рацион, указывая массу в граммах.
5. Пользователь открывает страницу анализа и получает вывод по рациону.
6. Пользователь открывает дашборд и анализирует рационы по нескольким датам.

## 7. Изменения в ходе реализации
- Изначально проект планировался как простой сервис расчета КБЖУ и стоимости.
- В процессе реализации были добавлены:
  - страница профиля с формой редактирования,
  - отдельная страница анализа,
  - выбор рационов по дате,
  - рекомендации по продуктам,
  - бюджетные рекомендации,
  - дашборд с графиками на Pandas и Plotly.
